# Política de privacidade

O Radar de Notícias com IA é um projeto pessoal de portfólio. Ele roda localmente, no computador do autor, e não é oferecido como serviço a outras pessoas.

## Acesso à conta Google

O projeto usa uma autorização do Google (OAuth) somente na conta do próprio autor, para:

- enviar o relatório de notícias por e-mail, pelo Gmail;
- registrar as notícias enviadas e o histórico de execuções em uma planilha do Google Sheets.

Os e-mails existentes na conta não são lidos pelo projeto.

## Dados

- O projeto não coleta dados de outras pessoas.
- Nenhum dado da conta Google é vendido, compartilhado ou usado para treinar modelos de IA.
- Os dados de acesso ficam guardados nas credenciais criptografadas do n8n, no computador do autor.
- Só notícias públicas são enviadas à API do Gemini, que escreve os resumos.

## Como revogar o acesso

A autorização pode ser removida a qualquer momento em [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
